# Changesets

Hello and welcome! This folder has been automatically generated by
[Changesets](https://github.com/changesets/changesets).

A changeset is a small markdown file that describes a change to a package and
the semver bump it requires. Add one with:

```bash
bun run changeset
```

Changesets are consumed by the release workflow: on `main` it opens or updates
a "version packages" pull request, then publishes to npm once that PR merges.
